# Реестр модулей

Title: Module registry · Status: FINAL · Version: 1.0 · Date: 27 September 2026

Источник — `src/lib/directions.ts`; та же таблица показывается на `/ru/status`.

## Работает

| Модуль | Состояние и граница |
| --- | --- |
| Аккаунты и сессии | Регистрация 18+, вход, выход, смена пароля, управление сессиями, ограничение попыток входа. |
| Игровой паспорт | Профиль с историей матчей и турниров; у каждого результата — событие, дата и способ проверки. |
| Команды | Владелец, капитан, приглашения с принятием и отказом, передача полномочий. |
| Пространства организаторов | Сотрудники с ролями владельца, администратора и судьи; изоляция прав между пространствами. |
| Турнирный движок: олимпийская система | Любое число участников, проходы без игры для верхних посевов, посев, лист ожидания, check-in, состояния с разрешёнными переходами. |
| Игровой день и результаты | Отчёт участника, подтверждение соперника, споры, решение судьи, неявка, дисквалификация, исправление с версиями. |
| Итоги и рейтинги | Итоговые места и таблицы по играм только из подтверждённых матчей. |
| Центр управления | Пользователи, роли, блокировки с причиной, очередь споров, очередь заявок, журнал с проверкой hash-цепочки. |
| Заявки партнёров и направлений | Сохраняются в базе и попадают в рабочую очередь администрации. |
| Уведомления на портале | Приглашения, готовность матча, результаты, споры, изменения турнира. |
| Приватность данных | Публичность профиля, выгрузка своих данных, удаление аккаунта с обезличиванием. |
| Интерфейс RU / EN | Локализованные маршруты и переключение языка на той же странице. |

## Требует подключения

| Модуль | Состояние и граница |
| --- | --- |
| Восстановление доступа по email | Требуется почтовый сервис. Сейчас восстановление — через поддержку. |
| Интеграции с издателями игр | Требуются одобренный доступ и ключи (Riot RSO, Steam, PUBG API и др.). До подключения — ручная проверка с доказательствами. |
| Серверный контур CS2 | Provisioning, RCON, demo и восстановление матчей — на отдельной инфраструктуре. |
| Загрузка файлов-доказательств | Требуется файловое хранилище. Сейчас доказательства — ссылками. |
| Платежи и подписки | Провайдер под допустимый сценарий не подключён; платных операций нет. |
| White-label домены | Собственный домен и оформление партнёра. |

| Медиа и трансляции | Live-центр, VOD, клипы, оверлеи. |
| Сообщества, сообщения, голос | С модерацией и ограничениями для несовершеннолетних. |
| Площадки, Clubhouse, QR check-in | Только подтверждённые адреса и статусы. |
| Прогрессия: XP, уровни, достижения | Без денежной стоимости баллов. |
| Магазин и маркетплейс | Только реальные заказы и подтверждённые товары. |

| Опекуны, школы и благополучие | Согласия с версиями, лимиты времени и расходов, ограничения контактов. |
| MFA для сотрудников | Повторная проверка для чувствительных операций. |
| Облачный гейминг и аренда серверов | Отдельная инфраструктура; сейчас принимаются заявки. |
| Gamer dating 18+ | Отдельный добровольный продукт со своим согласием; не смешивается со школьными и детскими пространствами. |

## Исследование

| Модуль | Состояние и граница |
| --- | --- |
| Собственный античит и ML-сигналы | Kernel-компонент не включается автоматически; сигналы модели — повод для проверки, не доказательство. |
| Анализ CCTV для безопасности площадок | Только при отдельном обосновании и допустимости. |
| Анализ реакции зрачка | Не применяется к игрокам: никаких выводов о здоровье, личности или честности. |
| Идентичность ACEXIS | Направление цифровых решений из учёта IP; не является игровым продуктом. |
| ИИ-аналитика продаж, персонализированные новости и лояльность | Для партнёрских программ и разрешённых рекомендаций. |
