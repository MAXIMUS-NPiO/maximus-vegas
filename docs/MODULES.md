# Реестр модулей

## Работает

| Модуль | Состояние и граница |
| --- | --- |
| Аккаунты и сессии | Регистрация 18+ с фиксацией принятых версий условий, вход, выход, смена пароля, управление сессиями, ограничение попыток входа. |
| Игровой паспорт и репутация | Профиль с историей матчей и турниров, рангом и репутацией по итогам оспариваний. |
| Команды | Владелец, капитан, приглашения, передача полномочий, логотип и баннер. |
| Пространства организаторов и со-организаторы | Роли владельца, администратора и судьи; со-организаторы отдельного турнира; ограничение по странам. |
| Олимпийская система и double elimination | Проходы без игры для верхних посевов, нижняя сетка, гранд-финал и перезапуск финала; посев по ручным номерам, затем по XP, затем по порядку регистрации. |
| Круговая и швейцарская системы | Один или два круга; швейцарские пары по очкам без повторных встреч и bye по правилам; ничьи по выбору организатора. Tie-breakers Buchholz, Median Buchholz и Sonneborn-Berger (MV-STANDINGS-1, MV-SWISS-1), настройки фиксируются при старте. |
| Многоэтапные турниры: группы, лиги и плей-офф | Группы змейкой по посеву → плей-офф (олимпийская, двойное выбывание или лесенка); круговая или швейцарская → плей-офф лучших N. Посев плей-офф по местам в группах без встреч одногруппников в первом раунде, даты туров по интервалу, фиксация основного этапа после старта плей-офф (MV-STAGES-1). |
| Лесенка (gauntlet) | До 16 участников: нижние посевы играют первыми, победитель поднимается к следующему посеву, первый посев играет только финал; места уникальны. |
| Серии Bo1–Bo7 и очки по уровням | Формат серий и очки наследуются: турнир → плей-офф → нижняя сетка → группа → тур или стадия → матч; счёт серии проверяется по числу побед, судья может изменить отдельный матч до результата (MV-SERIES-1). |
| FFA: лобби с очками за места | Лобби змейкой по посеву, несколько игр в раунде, очки за место и убийства, выход лучших из каждого лобби до финального лобби; результаты вносит судья с версиями, споры по игре, следующий раунд ждёт решения споров (MV-FFA-1). |
| Регистрация с подтверждением, допуском, вопросами и составами | Подтверждение или отказ с причиной, срок регистрации, критерии допуска (подтверждённый email, возраст аккаунта, опыт и матчи в игре — у каждого игрока состава), до пяти вопросов (ответы видят только организаторы и судьи), фиксация составов и замены через организатора с историей. |
| Серии и сезоны | Накопительные очки с весом турниров, квалификация в финалы, дивизионы с повышением и понижением, зафиксированная история сезонов в игровом паспорте (MV-CIRCUIT-1). |
| Шаблоны, оценки, копирование и безопасное пересоздание | Шаблоны турниров с категориями, статистикой и оценками участников по реальным турнирам; оценка турнира участниками в течение 30 дней; копия турнира в черновик; пересоздание сетки, тура, групп, плей-офф или лобби только до первого результата; предпросмотр структуры до старта; история турнира из журнала. |
| Leaderboard-турниры | Веса статистики, лучшие N результатов, окно отправки, tie-break по KDA и убийствам, проверка неправдоподобных строк (не античит). |
| Игровой день, расписание, результаты и споры | Отчёт, подтверждение, check-in к матчу, решение судьи, неявка после льготного времени, дисквалификация, исправление с версиями, оспаривание решённого матча; площадки, распределение тура по площадкам волнами, перенос тура и сдвиг расписания с уведомлениями, проверка пересечений площадок и участников, в том числе между турнирами (MV-SCHEDULE-1). |
| Итоги, рейтинги и награды | Итоговые места из подтверждённых матчей; титулы в рейтинге — первые места завершённых турниров; награда победителю в монетах назначается оператором и выплачивается один раз каждому чемпиону. |
| Прогрессия: XP, ранги, цели, сезонный пропуск | Начисления только за подтверждённую активность, без двойных начислений. |
| Монеты и косметика | Монеты без денежной стоимости: не покупаются, не выводятся, не передаются и не ставятся на исход. |
| Вызовы 1v1 и быстрый матч | Без ставок; быстрый матч соединяет только с реальными игроками из очереди. |
| Реферальная программа | Один код на аккаунт; награда пригласившему — после первого подтверждённого матча приглашённого. |
| Изображения: логотипы, баннеры, доказательства | PNG, JPEG, WebP с проверкой сигнатуры и лимитами; доказательства видят только участники матча и судьи. |
| Центр управления и MFA | Вход сотрудников со вторым фактором, повторная проверка для чувствительных решений, журнал с hash-цепочкой. |
| Заявки на членство и счета | Отдельные состояния заявки, счёта, оплаты и членства; условия фиксируются версией. |
| Заявки партнёров и направлений | Сохраняются в базе и попадают в рабочую очередь администрации. |
| Уведомления на портале | Приглашения, матчи, результаты, споры, вызовы, награды, счета. |
| Приватность данных | Публичность профиля, выгрузка своих данных, согласие на рассылки отдельно, удаление аккаунта с обезличиванием. |
| Интерфейс RU / EN | Локализованные маршруты и переключение языка на той же странице. |

## Требует подключения

| Модуль | Состояние и граница |
| --- | --- |
| Подтверждение email и восстановление доступа | Код готов: одноразовые ссылки со сроком действия и очередь писем с повторами. Нужен почтовый сервис (Resend или SMTP). |
| Онлайн-оплата членства | Код готов: hosted checkout, проверка подписи webhook, возвраты и споры. Нужны утверждённые условия предложения и подтверждённый мерчант MAXIMUS VEGAS L.L.C-FZ. |
| Интеграции с издателями игр | Требуются одобренный доступ и ключи (Riot RSO, Steam, PUBG API и др.). До подключения — ручная проверка с доказательствами. |
| Вход через Google, Steam, Epic | Нужны зарегистрированные приложения у провайдеров. Кнопки не показываются, пока вход не настоящий. |
| Серверный контур CS2 | Provisioning, RCON, demo и восстановление матчей — на отдельной инфраструктуре. |
| White-label домены | Собственный домен и оформление партнёра. |

## Исследование

| Модуль | Состояние и граница |
| --- | --- |
| Проверка статистики через API издателей | PUBG: телеметрия матча с фильтрацией убийств ботов; CS2: разбор demo по коду матча. Отдельная работа для каждой игры, ключи хранятся только на сервере. |
| Собственный античит и ML-сигналы | Античит в реальном времени требует компонента на стороне игры и не создаётся сайтом. Сигналы модели — повод для проверки, не доказательство. |
| Анализ CCTV для безопасности площадок | Только при отдельном обосновании и допустимости. |
| Анализ реакции зрачка | Не применяется к игрокам: никаких выводов о здоровье, личности или честности. |
| Идентичность ACEXIS | Направление цифровых решений из учёта IP; не является игровым продуктом. |
| ИИ-аналитика продаж, персонализированные новости и лояльность | Для партнёрских программ и разрешённых рекомендаций. |
