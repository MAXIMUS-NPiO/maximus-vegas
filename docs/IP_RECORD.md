# Запись компонентов для внутреннего учёта IP (MIPA)

Title: IP component record · Status: FINAL · Version: 2.0 · Date: 27 September 2026

MIPA — внутренний контур фиксации и управления IP. Эта запись — локальный манифест в репозитории; она не является государственной регистрацией и не заменяет запись во внутреннем реестре MIPA.

| Поле | Значение |
| --- | --- |
| Объект | Исходный код игрового портала MAXIMUS VEGAS, release 2.0 |
| Состав release 1 | Турнирный движок на выбывание с проходами без игры, проверка результатов с версиями и спорами, журнал с hash-цепочкой, аккаунты и игровой паспорт, команды, пространства организаторов, центр управления, интерфейс RU / EN |
| Состав release 2 | Double elimination с нижней сеткой, гранд-финалом и перезапуском; leaderboard с весами, best-of-N, окном отправки и проверкой неправдоподобных строк; оспаривание решённых матчей с переписыванием сетки и репутацией; со-организаторы и ограничение по странам; прогрессия (XP, ранги, цели, сезонный пропуск, косметика, монеты без денежной стоимости, рефералы); вызовы 1v1 и быстрый матч без ставок; изображения с проверкой сигнатуры; спонсоры; подтверждение email, восстановление, согласия с версиями, очередь писем; второй фактор TOTP для сотрудников; членство, счета и платёжный контур с проверкой webhook |
| Основание создания | Задание владельца от 27 September 2026: обновить MAXIMUS VEGAS по техническому handoff «Maximus Vegas — Technical Handoff & Requirements Spec» и эталонному архиву `maximus-vegas-backend.zip`, с инженерными стандартами промпта «MAXIMUS Club Portal — Website Update, Participant Registration and Payments» (Version 1.0, 27 September 2026) |
| Правообладатель | NOT PROVIDED — определяется решением владельца |
| Версия и хеш | Версия 2.0; хеш — идентификатор commit в `main` репозитория `MAXIMUS-NPiO/maximus-vegas` (фиксируется в отчёте о выпуске) |
| Происхождение | Новая реализация в стеке портала. Логика эталонного архива (Express + SQLite) перенесена и переработана; код архива в репозиторий не копировался. Код TournamentSuite и Banger не использовался: он не был предоставлен |
