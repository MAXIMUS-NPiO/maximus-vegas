# Запись компонентов для внутреннего учёта IP (MIPA)

Title: IP component record · Status: PENDING MIPA REGISTRATION · Version: 6.0 · Date: 1 October 2026

MIPA — внутренний контур фиксации и управления IP. Эта запись — локальный манифест в репозитории; она не является государственной регистрацией и не заменяет запись во внутреннем реестре MIPA.

| Поле | Значение |
| --- | --- |
| Объект | Исходный код игрового портала MAXIMUS VEGAS, release 6.0 |
| Состав release 1 | Турнирный движок на выбывание с проходами без игры, проверка результатов с версиями и спорами, журнал с hash-цепочкой, аккаунты и игровой паспорт, команды, пространства организаторов, центр управления, интерфейс RU / EN |
| Состав release 2 | Double elimination с нижней сеткой, гранд-финалом и перезапуском; leaderboard с весами, best-of-N, окном отправки и проверкой неправдоподобных строк; оспаривание решённых матчей с переписыванием сетки и репутацией; со-организаторы и ограничение по странам; прогрессия (XP, ранги, цели, сезонный пропуск, косметика, монеты без денежной стоимости, рефералы); вызовы 1v1 и быстрый матч без ставок; изображения с проверкой сигнатуры; спонсоры; подтверждение email, восстановление, согласия с версиями, очередь писем; второй фактор TOTP для сотрудников; членство, счета и платёжный контур с проверкой webhook |

| Состав release 5 | Формат FFA MV-FFA-1: лобби змейкой по посеву, игры с очками за место и убийства, таблица лобби, выход лучших с посевом между лобби по очкам за игру, раунды до финального лобби, итоговые места с общими местами, версии результатов, споры по игре, ожидание споров и фиксация прежних раундов; подтверждение заявок с отказом по причине и истечением при старте; срок регистрации; вопросы при регистрации с ответами только для руководителей турнира; составы на турнир с фиксацией и заменами через организатора с историей; шаблоны турниров с категориями и статистикой; перенос тура и сдвиг расписания; льготное время до неявки |
| Состав release 6 | Формат серий Bo1–Bo7 и очки таблицы с наследованием турнир → плей-офф → нижняя сетка → группа → тур или стадия → матч (MV-SERIES-1) с проверкой счёта серии и переопределением матча судьёй; очки каждого матча в таблицах и личных встречах; площадки турнира, распределение тура волнами и проверка пересечений площадок, участников и игроков между турнирами с подтверждаемым переопределением (MV-SCHEDULE-1); критерии допуска для каждого игрока состава; оценки участников с окном 30 дней и сводкой в шаблонах; история турнира из журнала |
