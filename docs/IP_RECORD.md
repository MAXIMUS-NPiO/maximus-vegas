# Запись компонентов для внутреннего учёта IP (MIPA)

Title: IP component record · Status: FINAL · Version: 1.0 · Date: 27 September 2026

MIPA — внутренний контур фиксации и управления IP. Эта запись не является государственной регистрацией.

| Поле | Значение |
| --- | --- |
| Объект | Исходный код игрового портала MAXIMUS VEGAS, release 1.0 |
| Состав | Турнирный движок (сетка на выбывание с проходами без игры), модуль проверки результатов с версиями и спорами, журнал с hash-цепочкой, аккаунты и игровой паспорт, команды, пространства организаторов, центр управления, интерфейс RU / EN |
| Основание создания | Техническое задание «MAXIMUS VEGAS — Промпт создания игрового портала», Version 1.0, 27 September 2026, по поручению владельца |
