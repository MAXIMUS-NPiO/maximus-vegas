## 3. Что изменилось

- Турниры: double elimination (нижняя сетка, гранд-финал, перезапуск), leaderboard (веса, best-of-N, окно отправки с отсчётом, проверка неправдоподобных строк), оспаривание решённых матчей с переписыванием сетки, репутация, со-организаторы, ограничение по странам, check-in к матчу, баннеры, спонсоры, награда победителю в монетах.
- Прогрессия без денежной стоимости: XP, ранги, цели, сезонный пропуск, косметика, реферальная программа; вызовы 1v1 и быстрый матч без ставок.
- Аккаунты: ошибки у полей, сохранение введённого при ошибке и смене языка, онбординг из 4 шагов, подтверждение email и восстановление пароля одноразовыми ссылками, режим «сначала email», согласия с версиями, отдельное согласие на рассылки, очередь писем с повторами, выгрузка и удаление с учётом новых данных.
- Центр управления: второй фактор TOTP для сотрудников, повторная проверка для чувствительных действий, 13 вкладок, включая членство, предложения, оплаты, письма, спонсоров и безопасность.
- Членство и оплаты: раздельные состояния заявки, счёта, попытки оплаты и членства; версии предложений; раскрытие условий до оплаты; hosted Checkout Stripe; проверка подписи webhook по сырому телу; идемпотентность и устойчивость к порядку событий; квитанции. Приём оплат выключен.
